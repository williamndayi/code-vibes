# Code Vibes

A modern, browser-based development environment for building websites and applications. Think Lovable meets Bolt, but with pure coding vibes! ✨

## Features

🚀 **Live Code Editor** - Monaco-powered editor with syntax highlighting and intelligent code completion
⚡ **Instant Preview** - See your changes come to life instantly with our live preview panel
🎨 **Professional Templates** - Start quickly with beautifully designed templates
📁 **File Management** - Intuitive file tree with drag-and-drop support
🔧 **Multi-Language Support** - HTML, CSS, JavaScript, TypeScript, React, and more
💾 **Auto-Save** - Your work is automatically saved to local storage
📱 **Responsive Design** - Works perfectly on desktop, tablet, and mobile

## Quick Start

1. **Choose a template** - Pick from our curated collection of professional templates
2. **Start coding** - Use our powerful Monaco editor to write your code
3. **See it live** - Watch your changes appear instantly in the preview panel
4. **Build amazing things** - Create websites, web apps, prototypes, and more!

## Templates

- **Basic Website** - HTML, CSS, and JavaScript starter
- **React App** - Modern React application with hooks and components
- More templates coming soon!

## Technology Stack

- **Next.js 14** - React framework with App Router
- **TypeScript** - Type-safe development
- **Tailwind CSS** - Utility-first CSS framework
- **Monaco Editor** - The editor that powers VS Code
- **Lucide React** - Beautiful, customizable icons

## Getting Started for Developers

```bash
# Clone the repository
git clone https://github.com/williamndayi/code-vibes.git
cd code-vibes

# Install dependencies
npm install

# Start the development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the application.

## Project Structure

```
src/
├── app/                 # Next.js App Router
│   ├── layout.tsx      # Root layout
│   ├── page.tsx        # Home page
│   └── globals.css     # Global styles
├── components/         # React components
│   ├── CodeEditor.tsx  # Monaco-based code editor
│   ├── FileTree.tsx    # File explorer
│   ├── PreviewPanel.tsx # Live preview
│   └── IDE.tsx         # Main IDE component
├── lib/                # Utility functions
│   └── templates.ts    # Project templates
└── types/              # TypeScript type definitions
    └── index.ts        # Shared types
```
